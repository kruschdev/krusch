# AGENTS.md — Krusch Coding Harness

> **Project**: `krusch`
> **Maintainer**: Kevin Ruschman (KruschDev)
> **Core Thesis**: Models are ephemeral compute; PostgreSQL is the brain. Keep workflow, context, tests, and approvals consistent while making models interchangeable.

---

## 🧭 System Principles & Invariants

1. **State Lives in PostgreSQL**:
   - Never keep primary task state, turn history, or proposed file edits exclusively in memory or transient scratchpads.
   - All state persists to `krusch_tasks`, `krusch_turns`, `krusch_events`, and `krusch_staged_diffs`.

2. **Pre-Commit Staging Invariant**:
   - File edits generated by LLMs must be staged into `krusch_staged_diffs` with SHA-256 validation.
   - Files are written to physical disk only after automated test verification passes and approval policy criteria are satisfied.

3. **Routing Discipline ("Don't spend a model call just to pick a model")**:
   - Stage 1 (L1) microsecond CPU heuristic gate intercepts obvious SQL, syntax, math, and closed-world tasks for $0.00 in <15µs (`krusch-pre-router`).
   - Escalate to frontier reasoning (`claude-3-7-sonnet`, `deepseek-r1`) only on ambiguous intent, high complexity, or repeated verification failures.

4. **Modular Self-Improvement**:
   - Failures must be attributed to specific modules (`ContextManagement`, `ToolUse`, `ObservationManagement`, `AgentLoop`) using `KruschModularRSI` rather than blind re-prompting.

## 🛠️ Key Commands

- `npm test`: Run full test suite (unit + PostgreSQL integration).
- `npm run test:unit`: Fast unit tests (router, normalizer, trajectory guard, modular-rsi).
- `npm run test:integration`: PostgreSQL lifecycle integration tests.
- `npm run migrate`: Apply `db/schema.sql` to PostgreSQL (`kdcode`).
- `./bin/krusch.js run "<goal>"`: Run CLI harness.
- `./bin/krusch.js route "<prompt>"`: Test cascade routing decision.
- `./bin/krusch.js mcp`: Run stdio MCP server.

---

## 📂 Architecture Map

- `bin/krusch.js`: CLI binary entry point.
- `src/brain/`: PostgreSQL state management, connection pooling, context retrieval (`krusch-context-mcp` bridge).
- `src/router/`: Cascade router integrating `krusch-pre-router` and `krusch-cascade-router`.
- `src/models/`: Normalized model adapters (OpenRouter, Anthropic, Gemini, Ollama, Mock).
- `src/workflow/`: `KruschStateMachine`, `KruschTrajectoryGuard`, `KruschModularRSI`.
- `src/verify/`: Ground-truth test runner and diff guards.
- `src/approvals/`: Human-in-the-loop and automated approval policies.
- `src/server/`: Model Context Protocol (MCP) stdio server.
